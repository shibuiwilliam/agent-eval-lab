# E4-5 Step-level judging (rubric and reference-policy agreement)

*日本語版: [E4-5.md](E4-5.md)*

## The five items
- Hypothesis: A step whose action has been mutated scores lower than the original under both rubric judging and reference-policy agreement
- Planted condition: 30 steps extracted from healthy v01 runs, each replaced with a wrong tool / wrong argument / destructive operation
- Control: Judge the unmutated steps twice to see stability
- Pass criteria: mutation_drop_rate_rubric >= 0.8, mutation_drop_rate_refpolicy >= 0.8, original_mean_score >= 3.5, rejudge_agreement >= 0.8
- Provenance: simulated

## Method
We extracted 30 steps from passing v01_baseline runs and built synthetic steps mutating each
into 3 kinds (wrong tool / wrong argument / destructive operation) (report 4.6).
The rubric judge's input is "the events of the last 3 steps + the expected tool + whether the
state changed"; the agent's self-report text is not included (separating claim from evidence,
per 5.2).
Reference-policy agreement sends the same prefix to the reference policy K=5 times and measures
the fraction where the action's equivalence class (tool name + normalised arguments) matches.
For mutated steps we look at how often the mutated action matches what the reference policy
produces.
Re-judge agreement is the fraction of cases where judging the same input twice yields scores
within ±1.
Because live was unavailable, the judge is the deterministic surrogate and the reference policy
is the simulator (provenance simulated).

## Findings and limitations
- The judge is the deterministic surrogate, so the re-judge agreement rate is 1.0 by definition. With live Sonnet it should be below 1.0, so this number does not amount to having verified "judging stability". It is an item needing re-measurement under live — which E0-2 then did (within ±1: 1.000, exact: 0.967).
- The degradation rate of reference-policy agreement is 1.0 because mutated actions fall outside the reference policy's equivalence class. That too is a consequence of using the surrogate (the simulator) as the reference policy, and is not the value one would get with live Sonnet as the reference policy.
- Mean reference-policy agreement (original steps): 0.972
