# E8-6 Detecting a model swap by fingerprinting

*日本語版: [E8-6.md](E8-6.md)*

## The five items
- Hypothesis: Comparing distributions over fixed probes raises no alarm when the same model is re-sampled, and raises one when the model is swapped
- Planted condition: Swapping Haiku → Sonnet (a stand-in for a silent update)
- Control: Sampling Haiku twice
- Pass criteria: control_false_alarm_rate <= 0.1, swap_p_value < 0.05, live_control_p_value >= 0.05, live_swap_p_value < 0.05
- Provenance: live

## Method
Using the fixed 30 probes in `data/fixtures/probes.yaml` (no tools, short answers) plus 10
mini-tasks, we took a fingerprint from the response-length distribution, the first-20-character
agreement rate, and the tool-selection distribution (report 8.8).
The reference distribution is the difference obtained by sampling the same model twice, taken
as the null; detection is a permutation test at p < 0.05.
The false-alarm rate of the control (sampling the same model twice) was measured over 20
bootstrap rounds.
**Important**: for the artificial-distribution part, probe responses come from a deterministic
stand-in generator whose response lengths and endings differ by model — they are not real Haiku
or Sonnet responses. That part therefore verified only that the fingerprint statistic and the
permutation test react to a difference in distributions. The live fingerprint below is what
tests a real model swap.

## Findings and limitations
- **Live fingerprint (IMPROVEMENT.md R2)**: on the real API we sampled Haiku 4.5 twice and Sonnet 5 once (30 probes + 10 mini-tasks × 3 rounds = 120 calls). Mean response length was 58.2 characters for Haiku and 29.4 for Sonnet.
- **The pre-revision composite statistic could not detect the swap**: control p = 1.0, swap p = 0.1178 (above 0.05). On the artificial distribution it had detected it at p = 0.002, so that result had been propped up by the artificial distribution.
- ADR-013 removed the non-discriminating terms (first-character agreement, tool-selection distribution) from the statistic. A response-length-only permutation test separates cleanly: control p = 0.7161, swap p = 0.0455. The first-character agreement rate is 0.2 even for the same model twice and 0.1 across models — almost no difference — and 80% of the mini-task tool selections collapsed to `__no_tool__` (the real model answers in prose).
- That said, with 30 probes the swap's p is right at the edge of 0.05. It will not be stable without more probes, or mini-tasks that reliably force a tool call.
- The artificial probe responses come from a stand-in generator: the Haiku role averages 40 characters, the Sonnet role 90, with different opening phrasings and tool-selection distributions. That part artificially constructs "two groups that differ" and feeds them to the test, so detecting the swap there is structurally inevitable.
- What that part really confirmed is two things: (1) no false alarm on the control (two groups from the same distribution), and (2) the permutation test's p value is computed as implemented. Whether a silent update of a real model can be detected is answered by the live fingerprint above.
