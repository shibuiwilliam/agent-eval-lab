# EC-R2 Realizable pass@k: retrying until green amplifies silent errors

*日本語版: [EC-R2.md](EC-R2.md)*

## The five items
- Hypothesis: The success and silent-wrong rates of the retry policy 'accept the first visibly green trial, at most k tries' follow a closed form, versions with more W have a larger gap G_k between pass@k and the realizable success rate, and retrying increases W.
- Planted condition: c13_minimal_fix (intended to raise w; pinned to U1; the operation check failed, ADR-046). The trial pool is shared with EC-R1.
- Control: Observed w = 0 tasks and a synthetic grid for the identity P_k(success) = pass@k; the c12_null vs c01 gap is recorded only.
- Pass criteria: closed_form_mae_k1to4 <= 0.11, g3_diff_ci_low > 0, silent_wrong_monotone_c13 == 1, silent_wrong_gain_c13_ci_low > 0 (applies if c13_f_hat >= 0.15), identity_error_w0 <= 1e-09
- Provenance: live

## Method
From corpus-stage live trial classes, compare the closed form with empirical values (first half estimates, second half measures), compute G_3 differences and the silent-wrong gain by task-clustered bootstrap, and run the identity and monotonicity self-checks. Resampled and synthetic values are simulated. See docs/results/EC-R2.md.

The silent-wrong gain criterion did not apply because its condition c13_f_hat >= 0.15 is false (c13_f_hat = 0.0625 [live]; insufficient power at the attainable ceiling), so H3 (retrying increases silent errors) was not tested by this corpus: it is neither supported nor refuted. H1 (closed form): weakly supported, MAE 0.0124 [simulated]; with f near 0 the closed form is almost constant in k. H2: supported by the G_3 difference 0.075 [0.021, 0.135] [simulated] (G_3: c13 0.108, c01 0.033; c13's pass@3 0.844 overstates the realizable success rate 0.736), but the lower bound is thin, only 10 tasks contribute, and it is a restatement of EC-R1's W difference in pass@k terms rather than independent evidence. The two self-checks (monotonicity, identity error 2.2e-16) are not evidence for H3. Repeats were independent (identical_trial_rate 0; cassette_salt_check 0 defects in 336 runs).

## Findings and limitations
- The threshold 0.11 of closed_form_mae_k1to4 was fixed in W3-A2 from the c01 pilot (ADR-033; the EC-R2 entry of registry.yaml is authoritative). MAE by version: c01 0.010, c13 0.014. The criterion compares only P_k(success); in the recorded P_k(W), c13's closed form and empirical values differ by 0.041-0.056 because c13's W frequency fell by 0.056 from the first three repeats to the last three. Between 72 trials this is indistinguishable from chance and is not read as temporal drift.
- silent_wrong_monotone_c13 and identity_error_w0 almost always pass by definition; they are self-checks, not evidence for H3. H3's quantitative claim is tested by silent_wrong_gain_c13_ci_low (the W added by retrying), which applies only when c13_f_hat >= 0.15; otherwise it is N/A (insufficient power, not a pass; ADR-045). Here c13_f_hat = 0.0625, F and W rarely occur in the same task, and the F runs are harness truncations (max_tokens), so outside retries rarely happen: silent_wrong_gain_c13 = 0.0069 [0, 0.018] and P_k(W) saturates at k = 2 (0.236 to 0.243). "Retry until green" already happens inside the run (the agent calls run_tests and edits until green before finishing), so the k = 1 W rate already includes that inner amplification; re-testing H3 means measuring inside the run in stage 2.
- Independence diagnostic: identical_trial_rate = 0.0 (recorded only; near 0 when cassette salts work). A salt failure is checked separately: if the step-0 salted cassette key of a repeat is missing or duplicated within a (task, version) group, the experiment is forced to FAIL regardless of the criteria; here cassette_salt_check checked 336 runs and found 0 defects. If the cassettes cannot be read it is recorded as unverifiable.
- c12 has only 2 trials, so G_3 cannot be enumerated; the c12 vs c01 difference is recorded as G_2 (g2_diff_c12_minus_c01, recorded only), and the k = 5, 6 table is given only for the 6-trial versions (c01, c13). Retry ROI (recorded only, simulated): the optimal k over Theta splits between k = 1 and k = 6 (c01 0.27 / 0.73, c13 0.48 / 0.52), as the theory predicts; c13's observed w/s 0.337 exceeds the median threshold 0.171 (c01 0.084), but with f this small the NV differences between k values are tiny.
- The closed form assumes exchangeable trials within a task and the empirical value resamples the same pool, so the comparison cannot detect violations such as collapsed repeats; the weight of the claim rests on g3_diff_ci_low and silent_wrong_gain_c13_ci_low. G_k arises only in tasks where both S and W occur, so the G_3 difference restates EC-R1's W difference for "W mixed with S" and is not independent of it. Partial fixes counted as S (EC-R1's hidden-test strength note) would, if more frequent in c13, bias the G_3 difference and the W gain downwards.
