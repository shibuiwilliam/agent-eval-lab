# E3-9 Uncertainty's role is exploration (keeping the selector calibrated)

*日本語版: [E3-9.md](E3-9.md)*

## The five items
- Hypothesis: H(p-hat) exists to keep the selector calibrated, not to reduce this round's escape-defect rate
- Planted condition: The 37 synthetic changes processed sequentially under partial feedback; exploration ratios 0 / 0.05 / 0.2
- Control: epsilon = 0 (pure exploitation). Full observation reported as the ceiling
- Pass criteria: calibration_gain > 0.0, escape_gain >= 0.0, exploration_cost <= 0.1
- Provenance: simulated

## Method
E3-3 showed that selecting by `H(p-hat)` does not reduce this round's escape-defect rate. This experiment tests the *other* role report 3.8 gives ε-exploration: "keeping the selector calibrated".

The 37 synthetic changes are processed sequentially in a family-interleaved order under **partial feedback**. Each round (1) trains only on the rows observed so far, (2) selects greedily by `p_fail / cost` up to a 30% budget, and (3) **observes only the results of the selected tests**. Exploration ratios ε ∈ {0.0, 0.05, 0.2}, with the exploration slot filled either by top-`H(p-hat)` or at random.

Each round records the recall of that round's regressions, the escape-defect rate, and the Brier score **over all of that round's tests** (including unobserved ones; used for evaluation only, never for training). Calibration is compared on the late rounds.

**Robustness**: to keep the conclusion from depending on a single ordering, five orderings are run and every metric is averaged. Because the orderings are shared across policies, the comparison is **paired**.

- **A single ordering did not settle it.** The first implementation tried only one ordering of the changes, and on that ordering the calibration gain read +0.006. With five orderings and a **paired** comparison (the same ordering for ε=0 and ε=0.05) the gain becomes -0.0023 (paired SD 0.0088): **the effect disappeared**. The single-ordering result was picking up ordering-to-ordering variance.
- **Power**: detecting an effect of this size at 80% power would need 113 orderings (407 for the escape-defect rate). Five is nowhere near enough. So this experiment did not show that exploration fails to improve calibration — it showed that **any such effect is smaller than five orderings can resolve**. The result is inconclusive in both directions.
- **The cost of exploring stayed within the criterion.** The recall given up in the current round averages 0.0487 (criterion 0.10), while the rounds where exploration won gained 0.0576. **On balance exploration is slightly ahead.** At minimum, the worry that "exploration sacrifices a lot of current-round performance" is refuted.
- Full observation (complete information) has a late-round Brier of 0.088, **worse** than partial observation at ε=0 (0.068). More data does not always calibrate better: full observation feeds in a large number of easy negatives, which in this low-positive setting shrinks the predicted probabilities. The control intended as a ceiling did not act as one.
- The verdict is NEGATIVE. The hypothesis (exploration keeps the selector calibrated) could be **neither confirmed nor refuted**. This is not an implementation flaw: at this scale (37 changes, 108 positives) the effect size is buried in ordering variance. The criterion `calibration_gain > 0` implicitly assumes the effect is larger than the measurement error, and that assumption did not hold. The next step would be 100 orderings, or several hundred synthetic changes.
